# Londres · Navidad 2026

App del viaje de Javier, Alba, Manuel, Marta, Alfredo y Ángela (26–29 de diciembre de 2026). Es una web instalable, sin compilación: se publica tal cual esta carpeta.

## Publicar en GitHub Pages

1. github.com → **New repository** → nombre `londres-navidad26` → **Public**.
2. **Uploading an existing file** → arrastra **todo el contenido de esta carpeta** (incluida `cal/`) → Commit.
3. **Settings → Pages** → Deploy from a branch → `main` / `(root)` → Save.
4. La dirección será `https://<usuario>.github.io/londres-navidad26/`.
5. Si el usuario de GitHub no es `pereamunuaga-gif`, cambiadlo en `SYNC_CFG` (dentro de `index.html`).

## En el móvil

- **iPhone:** abrir el enlace en **Safari** (no dentro de WhatsApp) → Compartir → **Añadir a pantalla de inicio**.
- **Android:** Chrome → menú ⋮ → **Instalar app**.
- Abridla una vez con cobertura: después funciona sin conexión, con los dos expedientes.

## Modo organizador (Javier)

1. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token.
2. Repository access: **solo** `londres-navidad26`. Permissions → **Contents: Read and write**. Caducidad: 30 días.
3. En la app: tocar el círculo con las iniciales → Configuración → pegar la clave → «Guardar y comprobar».
4. Desde ahí se editan el aviso, la dirección del apartamento, el minibús, el enlace del grupo de WhatsApp y la ruta (en el Programa). «Publicar para todos» lo guarda en `ruta.json` y los demás lo ven en unos minutos.

La clave se queda solo en el móvil de Javier. No la compartáis: el repositorio es público.
